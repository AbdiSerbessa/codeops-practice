# Mesob House Web Application

**Project Overview**
A responsive web application designed for **Mesob House**, delivering an authentic Ethiopian culinary and digital hospitality experience. Built with a pixel-perfect design language derived directly from Desktop and Mobile Figma specifications, the platform serves users across viewports with tailored UI/UX patterns.

---

**Key Features & Highlights**

* **Authentic Ethiopian Aesthetic**: Rich earth-tone palettes (`#fdf8f4`, `#8b261d`), serif typography, and custom cultural elements like member badges and ceremonial quote highlights.
* **Dual-Viewport Architecture**: Fully responsive web design featuring dedicated desktop layouts alongside native-like mobile interfaces (including fixed bottom-tab navigation, mobile headers, and single-column stacked forms).
* **High-Fidelity Auth & Onboarding**: Seamless registration and login workflows incorporating localized Ethiopian phone verification logic (`+251`), password validation rules, and interactive dining preference selector chips.
* **Integrated Trust & Loyalty Systems**: Custom banner badges highlighting member perks (Tej/Buna welcome gifts, Communal Gursha loyalty points, and Fasting Calendar alerts).

---

**Tech Stack**

* **Frontend**: React.js, React Router DOM v6, Custom CSS Modules / Flex & Grid Architecture
* **Design & Prototyping**: Figma (Desktop & Mobile viewports)
* **Build Tooling**: Vite
