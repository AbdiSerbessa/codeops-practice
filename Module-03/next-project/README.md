# Addis Eats 🇪🇹
A modern traditional Ethiopian restaurant and food ordering web application built with Next.js, React, and Tailwind CSS.

## Deployed URL
* **Production Link:** [https://codeops-practice.vercel.app/]

---

## Features
* **Interactive Menu & Catalog:** Browse traditional Ethiopian specialties like Doro Wat, Beyaynetu, Kitfo, and etc with instant category filtering and detailed dish views.
* **Simulated Real-Time Tracking:** Live order status updates utilizing SWR data fetching patterns.
* **Debounced Search:** Smooth, performant menu searching with zero layout lag.
* **Advanced SEO & Metadata:** Fully optimized with dynamic and static Open Graph social preview images (`opengraph-image`), automated sitemaps, robots configuration, and structured data.

---

## Tech Stack
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Data Handling:** Client-side state and mock data structures
* **Deployment:** Vercel
