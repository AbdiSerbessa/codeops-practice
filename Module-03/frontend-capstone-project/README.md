# Addis Eats — Traditional Ethiopian Cuisine & Ordering Platform

Addis Eats is a full-stack web application built with **Next.js App Router** designed to bring authentic Ethiopian dining, seamless digital cart management, and real-time order tracking to customers and restaurant staff.

## 🚀 Live Demo
- **Production URL:** [https://codeops-practice-f4qz.vercel.app](https://codeops-practice-f4qz.vercel.app)

---

## 🛠️ Tech Stack
- **Framework:** Next.js (App Router, Server & Client Components)
- **Styling:** CSS / Modern Responsive Layouts
- **State Management & Routing:** Next.js File-system Routing & API Routes
- **Deployment:** Vercel

---

## ✨ Core Features
- **Interactive Menu Browser:** Explore traditional dishes (e.g., *Doro Wat*, *Kitfo*, *Beyaynetu*) categorized by preferences with high-resolution imagery and pricing in ETB.
- **Dynamic Cart & Checkout:** Real-time quantity adjustments, subtotal calculations, and order placement.
- **Live Order Tracking (`/track/[id]`):** Track active order progression and delivery status.
- **Admin / Kitchen Dashboard (`/dashboard` & `/kitchen`):** Comprehensive business metrics, daily performance overview, and live order status management.
- **Secure Authentication:** Protected route middleware and session-based user authentication.
