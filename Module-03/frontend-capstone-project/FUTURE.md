# Future Roadmap (FUTURE.md)

This document outlines features and enhancements triaged out of the initial capstone release to ensure core delivery stability and performance.

1. **Real-Time WebSockets / Push Notifications:** 
   - *Reason:* Deferred to avoid deployment complexity with Server-Sent Events/WebSockets on initial hosting layers; current polling/server actions suffice for order updates.
2. **Customer Dish Reviews & Ratings:** 
   - *Reason:* Enhances user engagement but is non-critical for the core ordering and admin management lifecycle.
3. **Multilingual UI Localization (Afaan Oromoo / Amharic):** 
   - *Reason:* Planned for post-launch iteration once the core English platform stability is verified.
